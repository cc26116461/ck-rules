# CK的规矩

## 作用

把一份 Markdown 里的对话规矩注入每次会话的系统提示。适合放这几类内容：

- 什么该问、什么该直接做
- 说话风格
- 不确定时怎么表达
- 自己的目录和交付习惯

## 安装

在 DSH 里打开「插件」，选择「添加插件」，指向本包所在目录，然后重启 DSH。

## 使用

装好后不需要额外操作。改配置有三种方式：

1. 点输入框上方的「CK的规矩」条，在里面换档位、改称呼 —— 下一轮生效，不用重启
2. 编辑 `cordis.patch.yml` 里的 `config`，重启生效
3. 把自己的规矩写成一个 `.md`，把绝对路径填进 `promptFile`

面板保存时会写进当前 profile 的配置（官方配置服务），所以重装插件也不会丢。

## 权限档位

| 档位 | 行为 |
|---|---|
| `loose` | 读写都直接执行 |
| `standard` | 只读直接执行；写入、改配置、删除前先确认 |
| `strict` | 每步都确认 |

## 需要注意

- 这是写给模型的约定，不是系统级沙箱。文件隔离仍由 DSH 的文件策略负责。
- 与其它注入插件同时启用会得到两段并存的规矩；只保留一套。
- 规矩文件缺失时插件照常启动，只在日志里警告。
